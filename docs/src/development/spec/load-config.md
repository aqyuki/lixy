# 設定の読み込み

## 設定の管理方針

Lixy は、環境ごとの既定値を YAML ファイルで管理し、実行時の上書き値やシークレットを環境変数で受け取る。
各設定項目の型・必須条件・対応する環境変数は、[設定と環境変数](../configuration.md)を参照すること。

| 設定元        | 役割                                               | 管理方法                                         |
| ------------- | -------------------------------------------------- | ------------------------------------------------ |
| YAML ファイル | 環境ごとの既定値                                   | Git で管理し、アプリケーションバイナリに埋め込む |
| 環境変数      | 実行環境の指定、既定値の上書き、シークレットの注入 | アプリケーションの起動前に実行環境へ設定する     |

シークレットを YAML ファイルに記載してはならない。
シークレット用の設定項目を追加する場合は、YAML ファイルにはキーと型に応じたゼロ値を記載し、実際の値は環境変数で設定する。

## 実行環境と設定ファイル

設定ファイルは `config/env/<env>.yaml` に配置する。`<env>` は実行環境を表し、次の値を使用する。

| 実行環境 | 用途                   | 設定ファイル            |
| -------- | ---------------------- | ----------------------- |
| `local`  | ローカル開発           | `config/env/local.yaml` |
| `test`   | 単体テスト・結合テスト | `config/env/test.yaml`  |
| `prd`    | 本番運用               | `config/env/prd.yaml`   |

実行環境は、起動時の環境変数 `LIXY_APP_ENV` で指定する。
この変数は YAML ファイルを選ぶために必要であり、YAML ファイル内の `app.env` では代替できない。
未設定の場合に使用する既定の実行環境は設けない。

実行環境の指定は、前後の空白を除去し、小文字に変換して解釈する。
たとえば、`LOCAL` や `local` は `local` として扱う。空文字列や登録されていない値はエラーとする。

各 YAML ファイルの `app.env` は、ファイル名の `<env>` と一致させる。
実行時はバイナリに埋め込まれたファイルを読み込むため、YAML ファイルの変更を反映するにはバイナリを再ビルドする必要がある。

## 読み込みの流れと優先順位

設定は、アプリケーションの起動時に次の順序で読み込む。

1. 環境変数 `LIXY_APP_ENV` を読み取り、実行環境を決定する。
2. 実行環境に対応する、埋め込み済みの YAML ファイルを読み込む。
3. `LIXY_` で始まる環境変数を読み込み、対応する設定値を上書きする。

同じ設定項目が両方に存在する場合は、環境変数の値を優先する。
対応する環境変数が設定されていない項目は、YAML ファイルの値を使用する。
空文字列が設定された環境変数も上書きの対象とし、未設定とは区別する。
上書きした値を設定項目の型に変換できない場合は、YAML ファイルの値に戻さずエラーとする。

## 環境変数と設定キーの対応

環境変数名は、次の規則で設定キーに変換する。

1. 接頭辞 `LIXY_` を取り除く。
2. 残りの文字列を小文字に変換する。
3. アンダースコア `_` を、階層の区切りを表すドット `.` に置き換える。

たとえば、`LIXY_APP_ENV` は設定キー `app.env`、YAML ファイルの `app` 配下にある `env` に対応する。
`LIXY_` で始まらない環境変数は、設定の上書きには使用しない。

## アプリケーション内での扱い

読み込んだ設定は `Config` 構造体に格納し、必要なモジュールに渡して利用する。
設定は起動時に一度だけ読み込み、実行中には再読み込みしない。
環境変数の変更を反映するには、アプリケーションを再起動する必要がある。

## エラー時の扱い

設定の読み込みに失敗した場合は、エラーとして起動を中止する。
別の実行環境の設定や、上書き前の値を使って起動を継続してはならない。

主なエラー条件は次のとおりとする。

- `LIXY_APP_ENV` が未設定、空文字列、または登録されていない値である。
- 対象の YAML ファイルが存在しない、または読み込めない。
- YAML ファイルの構文が不正である。
- 読み込んだ値を設定項目の型に変換できない。

# 設定

設定値の既定値は環境毎に`config/env/<env>.yaml`で管理されています。実行時に上書きしたいものやシークレット等は環境変数経由で注入してください。

::: warning
`config/env/<env>.yaml`はGitで管理されています。ここにシークレット等を記入しないでください。
シークレット等が必要な場合、YAMLにはキーを追加したうえでゼロ値を記入してください。
:::

## 設定項目

| 設定キー  | 環境変数       | 型                       | 必須 |
| --------- | -------------- | ------------------------ | :--: |
| `app.env` | `LIXY_APP_ENV` | `local` / `test` / `prd` |  ◯   |

## `app.env`

アプリケーションの実行環境を指定する。アプリケーション実行時には`LIXY_APP_ENV`経由での設定が必須である。

### 登録済みの環境

`app.env`には登録済みの環境以外を設定することはできない。設定した場合はエラーを出力して起動に失敗する。

- `local` ： ローカルの開発環境向け
- `test` ： 単体テストや結合テスト向け
- `prd` ： プロダクション環境向け
